# 小作业4：简化版卷积神经网络 (CNN) 实现

## 项目概述

本项目是《用纯Python手搓经典计算机视觉算法》开源教材的第四个小作业，实现了简化版的卷积神经网络(CNN)用于MNIST手写数字识别。项目完全使用纯Python、Numpy和Scipy库，从零开始实现了卷积层、池化层、全连接层等核心组件。

## 模型原理

### 卷积神经网络基础

卷积神经网络(CNN)是一种专门用于处理网格状数据（如图像）的深度学习模型。与传统全连接神经网络相比，CNN具有以下优势：

1. **局部连接**：每个神经元只与输入数据的局部区域连接
2. **权值共享**：在不同位置使用相同的卷积核
3. **池化操作**：降低特征图尺寸，增强模型鲁棒性

### 网络结构

本实现使用了一个简化的CNN结构：

```
输入层 (28×28×1) 
→ 卷积层1 (3×3, 4个滤波器) + ReLU → 最大池化 (2×2)
→ 卷积层2 (3×3, 8个滤波器) + ReLU → 最大池化 (2×2) 
→ 展平层 → 全连接层 (64个神经元) + ReLU → 输出层 (10个神经元) + Softmax
```

### 数学原理

**卷积操作**：
```
output[b, i, j, k] = ∑∑∑ input[b, i×stride+di, j×stride+dj, c] × filter[k, c, di, dj] + bias[k]
```

**最大池化**：
```
output[b, i, j, c] = max(input[b, i×stride:(i+1)×stride, j×stride:(j+1)×stride, c])
```

**反向传播**：使用交叉熵损失函数和梯度下降法更新参数。

## 实现细节

### 核心组件

1. **Conv2D层**：实现了多通道卷积操作，支持padding和stride
2. **MaxPool2D层**：实现了最大池化操作，记录最大值位置用于反向传播
3. **ReLU激活函数**：引入非线性特性
4. **Flatten层**：将多维特征图展平为一维向量
5. **Dense层**：全连接层实现
6. **Softmax层**：多分类输出层

### 技术特点

- **纯Python实现**：不依赖任何深度学习框架
- **模块化设计**：每个层都是独立的类，易于扩展和调试
- **完整的反向传播**：实现了从输出层到输入层的梯度计算
- **数值稳定性**：在Softmax和损失计算中考虑了数值稳定性问题

### 性能优化

- 使用Numpy向量化操作加速计算
- 实现批量数据处理，提高训练效率
- 添加梯度裁剪，防止梯度爆炸

**我**：我在实现卷积层时遇到了形状不匹配错误，输入区域形状(3,3,8)与权重形状(8,3,3)无法广播。

**LLM**：这是因为你的权重形状是(output_channels, input_channels, kernel_size, kernel_size)，但输入区域是(kernel_size, kernel_size, input_channels)。你需要调整循环顺序，先遍历输出通道，再遍历输入通道，在内部进行逐元素乘积累加。

**解决代码**：
```python
for out_ch in range(self.output_channels):
    for in_ch in range(self.input_channels):
```
