# 用纯Python手搓经典计算机视觉算法
## 📚 教材序言
在人工智能框架日益普及的今天，我们往往习惯于调用封装好的API快速搭建模型，却逐渐忽视了算法底层的数学原理与工程实现细节。本开源教材旨在打破这一壁垒，通过**纯Python+基础库**从零实现经典计算机视觉算法，让学习者亲手构建从简单分类器到基础神经网络的完整技术链路。

同时，本教材是**人机协作共创**的实践成果。在整个开发过程中，我们以百度文心大模型为协作伙伴，从项目架构设计、数学原理推导、代码调试优化到文档编写，全程记录了与LLM高效协作的完整流程。这不仅是一本算法实现指南，更是一份新时代下AI辅助学习与工程开发的实战手册。

通过学习本教材，你将收获：
1.  **扎实的理论功底**：深入理解每种算法的数学原理、损失计算、梯度传播等核心机制；
2.  **过硬的工程能力**：掌握模块化代码设计、数值稳定性优化、性能调优、可视化分析等实战技能；
3.  **高效的协作思维**：学会如何借助LLM解决技术难点，批判性验证AI输出，将工具转化为自身能力的延伸；
4.  **完整的开源项目经验**：从环境配置、版本控制到文档发布，全程遵循工业级软件工程规范。

本教材适合计算机视觉、深度学习入门学习者，以及希望夯实底层基础的开发者。无需复杂的框架基础，只要具备Python和基础数学知识，即可开启学习之旅。

## 📋 教材总目录
本教材采用**难度递进**的章节设计，共包含5个核心小作业和1个综合大作业，覆盖从传统机器学习到基础深度学习的经典算法，所有案例均基于MNIST手写数字数据集实现，确保学习的连贯性和实践性。

| 章节 | 作业名称 | 核心内容 | 学习目标 |
|------|----------|----------|----------|
| 第1章 | [K-近邻(K-NN)图像分类器](knn_classifier/) | 欧氏距离/曼哈顿距离计算、投票机制、交叉验证、参数调优 | 理解传统机器学习的惰性学习思想，掌握距离度量与模型评估的基本方法 |
| 第2章 | [Softmax线性分类器](softmax-classifier/) | Softmax函数、交叉熵损失、L2正则化、梯度下降参数更新 | 掌握线性分类器的数学原理，理解前向传播与反向传播的基础流程 |
| 第3章 | [两层全连接神经网络](two_layer_fc_net/) | ReLU激活函数、全连接层实现、Xavier初始化、动量SGD优化 | 入门深度学习，理解非线性激活与多层网络的特征学习机制 |
| 第4章 | [简化版卷积神经网络(CNN)](cv-handcraft-cnn/) | 卷积层、最大池化层、特征图展平、多通道特征提取 | 掌握CNN的核心优势（局部连接、权值共享），理解图像特征的层级提取过程 |
| 第5章 | [基础版循环神经网络(RNN)](rnn-basic/) | 序列数据处理、循环层实现、时序梯度传播 | 入门序列模型，为后续处理视频、文本等时序数据打下基础 |

## 🔧 统一技术栈
本教材全程坚持**无框架依赖**原则，所有算法仅基于基础Python库实现，确保学习者聚焦于算法本身而非工具使用。

### 核心依赖
```txt
Python 3.8+
Numpy 1.21+          # 数值计算核心
Scipy 1.7+           # 科学计算辅助
Matplotlib 3.5+      # 结果可视化
```

### 开发环境要求
- **系统环境**：必须使用虚拟Linux环境（Docker/WSL/虚拟机）
- **版本控制**：Git + GitHub（遵循约定式提交规范）
- **环境管理**：venv/conda虚拟环境
- **文档规范**：Markdown（统一文档风格）

## 🚀 快速开始
### 环境初始化
```bash
# 1. 克隆仓库
git clone https://github.com/luchengyang6/cv.git
cd computer-vision-from-scratch

# 2. 创建并激活虚拟环境
python -m venv cv_env
source cv_env/bin/activate  # Linux/Mac
# cv_env\Scripts\activate  # Windows（若使用WSL可忽略）

# 3. 安装依赖
pip install -r requirements.txt
```

### 章节学习指引
1.  每个章节（小作业）均为独立项目，包含完整的代码、文档和示例
2.  进入对应章节目录，参考该目录下的`README.md`执行具体的训练、测试和可视化命令
3.  建议按章节顺序学习，确保基础知识点的连贯性
4.  章节内均包含`llm_interaction_logs.md`，可查看完整的AI协作开发记录
